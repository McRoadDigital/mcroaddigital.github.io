McRoad Digital — Pinterest App Privacy Policy

Last updated: October 13, 2026. Operator: McRoad Digital. This policy covers our owner-only Pinterest integration, not the Seller Profit Tracker workbook or Gumroad checkout. It serves no outside customers.

Current data practices

Pinterest Trial access is approved; OAuth authorization, a live API test and Standard approval are not confirmed. The owner reports manually saving the OAuth2 credential in n8n; setup values, including the app secret and client ID, are entered directly in n8n rather than in chat. Saving that setup does not establish an authorized Pinterest connection. The workflow is inactive, manually triggered, and both Pinterest HTTP nodes are disabled. It has not run a live Pinterest API check.

Limited connection and data use

The initial connection requests only boards:read and pins:read. Upcoming owner-controlled OAuth processing receives an authorization code and obtains access and refresh tokens solely to authenticate the owner's own account. We do not request Pinterest passwords or session cookies.

A future owner-initiated GET check of boards or Pins transiently processes returned fields, which may include identifiers, names, descriptions and URLs, to validate read access and diagnose connection problems. Its configured summary whitelist contains only the endpoint label, HTTP status and item count for that response page, discarding other output fields. A page count is not an account-wide total.

There is no advertising, bulk or public posting, sale of Pinterest data, or access for outside users. Connecting alone authorizes no publication. Any extension, including write permissions, posting, additional users or materially different data handling, requires a policy update before use.

Providers, storage and limitations

Pinterest provides OAuth and API services. n8n on the owner's Hostinger infrastructure processes the connection and API responses. App credentials and, once obtained, access and refresh tokens stay in the n8n database until the owner disconnects and deletes the credential.

Minimal status/count summaries are reported to Hermes via MCP and sent to the configured ChatGPT/Codex provider for AI-assisted review. No raw Pinterest content or OAuth secrets are intentionally sent to the model. This limited summary is separate from the provider's own processing and retention terms; we promise no fixed provider deletion period.

As verified on October 13, 2026, all four workflow execution-save settings are off. These workflow controls do not establish that the hosting or software produces no technical logs, telemetry or backup copies.

n8n documents credential encryption. We have not audited host encryption-key persistence, backup encryption or retention, access controls, logging or telemetry. Technical logs and backup copies may follow hosting/software configuration and provider terms. We do not guarantee encrypted backups or immediate backup deletion. See Hostinger's privacy policy and Pinterest's privacy policy for their practices.

Retention, disconnecting and deletion

Minimal validation summaries are retained in private operational review notes while needed to establish or debug the connection, not for an invented fixed period. The owner may delete them or request deletion through the existing private Hermes conversation.

The owner can disable the workflow to stop its runs, delete the credential and any saved connection records in n8n, and remove the app in Pinterest's connected-app settings. Disabling alone does not delete credentials. Local deletion is not guaranteed Pinterest-side revocation; provider-held logs and backup copies may remain under their configuration and terms. Private access or deletion instructions can be supplied through the owner's existing private Hermes conversation; the owner can perform n8n deletion directly.

Website and questions

The static homepage and policy are served by GitHub Pages. McRoad Digital adds no forms, scripts, tracking pixels or cookies. GitHub may process IP addresses and security/request logs under its public privacy statement.

For non-sensitive questions, use our public GitHub issue contact. Issues are public: never include personal data, account details, credentials or secrets. Use the existing private Hermes conversation for owner-only access/deletion matters, not a public issue.
