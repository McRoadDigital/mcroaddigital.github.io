McRoad Digital — Pinterest App Privacy Policy

Last updated: October 13, 2026. Operator: McRoad Digital. This policy covers our owner-only Pinterest integration, McRoad Digital Selected Pin Publisher. It serves no outside customers and does not cover Gumroad checkout or the Seller Profit Tracker workbook.

Current access and owner-selected Trial test

Pinterest Trial access is approved. Authenticated board and Pin reads have been verified; Standard access, write authorization, Pin creation and automatic token refresh have not yet been verified. Trial-created Pins are visible only to their creator as Sandbox entities, not a public traffic channel.

The initial connection requested boards:read and pins:read. For a single owner-selected private test, the owner may authorize boards:read,boards:write,pins:read,pins:write, the scopes listed by Pinterest's Create Pin reference. The owner reports adding further categories and secret-content permissions in the n8n scope field; the permissions actually granted remain unverified. At the owner's request, manual read-only diagnostics may query public/secret boards and Pins, the owner's account, ad-account lists, catalog lists and business-employer membership to isolate authorization failures. Returned data is processed transiently and reduced to status/count/error-category summaries. We do not create ads, incur charges, modify catalogs, change business roles or edit/delete existing content as tests. No board creation is planned.

The test processes one owner-selected original PNG, title, description, alt text, destination URL, AI disclosure and an owner-controlled, non-group board identifier. The PNG is sent as Base64 directly to Pinterest, avoiding a separate public asset host. We do not automate schedules, bulk post, publish publicly, scrape or delete content in this test. Each actual Pin requires the owner's specific selection; account connection alone does not authorize posting.

Authentication and processing

The owner completes Pinterest OAuth consent directly through n8n. We never request Pinterest passwords or session cookies. App credentials, access tokens and refresh tokens stay in n8n's credential store until deleted by the owner; they are not intentionally copied into workflow fields, chat, files or operational evidence.

The workflow is inactive and manual-only. External request and evidence-write nodes remain disabled outside deliberate validation. During a single test, n8n transiently processes the create response and returned Pin identifier solely to read back that same Pin. Raw execution saving stays off. An ambiguous create result stops the attempt: no automatic retry or repeated POST is permitted.

Minimal evidence and providers

Private n8n tables and operational notes retain only validation summaries: endpoint or operation label, HTTP status, numeric API error code or fixed error-category label, page item count where relevant, match booleans and execution reference. Page counts are samples, not account totals. These summaries exclude Pin/board identifiers, creative, copy, URLs, raw response bodies, headers, tokens and credentials.

Pinterest provides OAuth and API services. n8n on the owner's Hostinger infrastructure processes requests, responses and credentials. Minimal summaries are reported to Hermes through MCP and sent to the configured ChatGPT/Codex provider for AI-assisted review. No raw Pinterest content or OAuth secrets are intentionally sent to the model. Original owner-selected outbound creative and copy may be handled by Hermes to configure the test; this is not retrieved Pinterest content.

Summaries are retained only while needed to verify or debug the integration and can be deleted on the owner's request through the private Hermes conversation or directly in n8n. We promise no fixed provider deletion period. No Pinterest data is sold or shared for third-party advertising.

Storage limitations, disconnecting and deletion

All four workflow execution-save controls are off. This does not establish that software, hosting or backups produce no logs, telemetry or copies. Host encryption-key persistence, access controls, backup encryption, retention and deletion propagation have not been audited. We do not guarantee encrypted backups or immediate backup deletion. Provider-held data follows provider configuration and terms.

The owner can disable workflows, delete minimal evidence and the n8n credential, and remove the app in Pinterest's connected-app settings. Disabling alone does not delete credentials. Local deletion is not proof of Pinterest-side revocation or immediate deletion from logs/backups. See n8n credential encryption documentation, Hostinger's privacy policy and Pinterest's privacy policy.

Website and contact

This static site is hosted on GitHub Pages. McRoad Digital adds no forms, scripts, tracking pixels or cookies. GitHub may process request/security logs under its privacy statement.

For non-sensitive questions use our public GitHub issue contact. Issues are public: never include account details, personal information or secrets. Owner-only access/deletion requests belong in the existing private Hermes conversation.
