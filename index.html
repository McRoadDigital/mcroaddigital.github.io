McRoad Digital Selected Pin Publisher

An internal Pinterest integration in development for McRoad Digital's own business account.

Proposed use

We are developing an app to prepare original educational Pins about our Seller Profit Tracker. The account owner would select each Pin and its destination and confirm before publishing. Connecting an account alone would not authorize publication.

We are requesting Pinterest API Trial access to develop and test OAuth, board selection and creation of a selected Pin. Public API publishing would wait for Standard approval. We do not propose bulk posting, scraping, advertising, messages, engagement manipulation or access for outside users.

Current status

This app is not yet connected to the Pinterest API. Live OAuth has not been implemented, and no Pinterest API calls or posts have been made by the app. Our local demonstration uses fictitious data. This page is informational, not a working app, checkout or software service.

Privacy and contact

Read our Pinterest app privacy policy for current data practices and GitHub Pages hosting disclosures. Before enabling real OAuth or API data handling, we will update that policy to describe the implemented controls and processing.

For non-sensitive questions, use our public GitHub issue contact route or our Pinterest business profile. Do not post personal information, passwords, app secrets or tokens in public issues.
