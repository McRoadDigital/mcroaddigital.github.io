McRoad Digital Selected Pin Publisher

An owner-only Pinterest integration for McRoad Digital's own business account. It serves no outside customers.

Current purpose

Pinterest Trial access and authenticated board/Pin reads are verified. We are preparing one manually controlled private Trial Pin test using an owner-selected original educational graphic and its direct Gumroad product destination. A separate isolated Sandbox test created one dedicated test board and the selected Pin, with successful API readback. Production Pin creation was rejected HTTP 403; public publishing and automatic token refresh remain unverified.

The workflow sends the original image as Base64 directly to Pinterest, creates one selected Pin only after deliberate authorization, reads it back once and retains only minimal status/boolean evidence. Trial-created Pins are visible only to their creator as Sandbox entities. This is not a public publishing service or a tested income channel.

Controls

The staged workflow is inactive and manual-only, with external and evidence-write nodes disabled and the release flag reset after the one successful Sandbox test. There is no bulk posting, scheduling, advertising, messaging, scraping, deletion or password/session-cookie collection. An ambiguous create result stops the attempt without automatic retry.

Privacy and contact

Read our Pinterest app privacy policy for requested scopes, data handling, providers, storage limitations and deletion. For non-sensitive questions use our public GitHub issue contact. Never include personal information, credentials or secrets in a public issue.
